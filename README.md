# Авіаційні силуети

Набір військових і цивільних літаків та гелікоптерів. Активний перелік
орієнтований на моделі, що експлуатуються, незалежно від року розробки.
Статус експлуатації решти кандидатів ще потребує перевірки за джерелами.

- 248 SVG-файлів загалом; 232 кандидати в активному каталозі.
- 16 історичних типів, прототипів і демонстраторів виключені з каталогу.
  Файли збережені; перелік і причини — у `catalog-excluded.json`.
- 100 іконок адаптовано з окремих SVG-референсів tar1090, Dump1090-OpenLayers3-html
  Plane Watch, AircraftShapesSVG та svg-air-vehicles, які переглянуто
  перед адаптацією. Геометрію збережено; колір, поля й підписи пристосовано
  до цього набору. Це не креслення виробника й не трасування фотографій.
- Інші нові контури не перевірені за референсами. Позначки якості є в каталозі.
- Початкові 28 SVG залишилися без змін.

## Перегляд

Відкрийте `index.html` або запустіть у корені репозиторію:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Каталог має пошук і категорії. Натискання картки відкриває SVG.
Іконки лежать у корені, мають прозоре тло й колір `#505a64`.
Для використання достатньо звичайного `<img src="f35.svg" alt="F-35">`.

`catalog.json` містить активний перелік і метадані. Поля `artwork`:
`original`, `individual`, `adaptation`, `reference-adaptation`, `template-draft`.
`reference_status: reviewed` означає звіряння з вказаним SVG-референсом,
а не незалежне підтвердження точності реального літака.
Джерела, модифікації, атрибуція й ліцензії записані в `references.json`.

## Робочий процес

Нові іконки створюються лише після пошуку й перегляду референсу конкретної
моделі. Повний процес описаний у [REFERENCES.md](REFERENCES.md).
Не використовувати геометрію іншої моделі лише зі зміненими пропорціями.

```sh
# Відтворити 100 адаптацій із зафіксованих даних референсів:
python3 tools/adapt_references.py
python3 tools/adapt_planewatch.py
python3 tools/adapt_aircraftshapes.py
python3 tools/adapt_airvehicles.py
# Оновити активний каталог і кореневі SVG:
python3 tools/generate_catalog.py
```

Стандартної бібліотеки Python 3 достатньо. Дані джерел лежать у
`third_party/tar1090`, `third_party/openlayers`, `third_party/planewatch`, `third_party/aircraftshapes` і `third_party/airvehicles`, адаптовані SVG — у `reference-artwork`.
Початкові файли не перезаписуються. У генераторі пріоритет такий:
референсна адаптація → окремий контур у `tools/overrides` → стара чернетка.

`tools/draw_fighters.py` відтворює попередні авторські контури без джерел.
Його наявність не робить їх референсними. Нові іконки за цим методом більше
не додаються. Ручні правки потрібно зберігати у відповідному джерелі SVG
або інструменті, інакше регенерація їх перезапише.
